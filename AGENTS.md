# User preferences

## Excalidraw

Unless the user explicitly asks otherwise, apply these defaults to any Excalidraw work in this repository:

- All text on the board is in English, even when the lecture is delivered in Arabic.
- Use a freeform, organic whiteboard composition. Avoid slide-like frames, uniform card grids, repeated headers/footers, and rigid presentation layouts.
- Prefer circles and ellipses, curved connecting arrows, branching diagrams, simple hand-drawn sketches, handwritten typography, underlines, and short annotations.
- Use restrained pastel highlights and plenty of whitespace. Let the visual relationships organize the content.
- Keep elements editable and provide an `.excalidraw` file. Check readability, text fit, and connectors before delivering.
- Reference style: an informal sketched idea map, with circled central concepts and surrounding examples. The user's reference images guide visual style, not lecture content.

These preferences were explicitly requested by the user on 21 October 2026. A later explicit request overrides them.
