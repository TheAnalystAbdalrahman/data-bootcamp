# Module 6 study guide: Excel Data Charts

**Original supplementary guide.** These examples are general Excel practice, not copied lessons or assessment answers. Work on copies of official files.

## Important concepts

- A chart should answer a specific question. Column charts compare categories, line charts show changes over an ordered sequence, and pie charts show parts of one whole when there are few categories.
- The source range determines categories and plotted values. Check the chart after adding or removing data so the range still covers the right records.
- A chart title states the subject. Axis titles and units prevent readers from guessing what values mean. Legends help when there are multiple series.
- Moving or resizing a chart should preserve readability and keep it from hiding important cells.
- Changing chart type or style can alter the story the reader perceives. Prefer accurate scales, clear labels, and restrained colors over decoration.
- Chart elements such as gridlines, data labels, and legends are optional. Keep only those that help interpretation.

## Original mini-exercise

Create a fictional table with four months in `A2:A5` and sales in `B2:B5`. Insert a column chart to compare the months, then a line chart to show the sequence. Add a title and label the value axis `Sales (units)`. Change one source value and confirm both charts update. For a separate three-category budget table, calculate each share with `=B2/SUM($B$2:$B$4)` and consider whether a pie chart or simple bar chart makes the comparison clearer.
