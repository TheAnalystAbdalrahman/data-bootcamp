# Excel Skills for Business: Essentials — study library

The [authenticated classroom](https://www.coursera.org/learn/excel-essentials/home/module/1) is accessible. The official weekly workbook lessons for Modules 1–6 each offered a ZIP download. All six untouched ZIP archives and their 45 extracted `.xlsx` files are organized under each module's `02_Official_Downloads` folder. One official English TXT transcript was downloaded from a Module 1 video; no video file was saved.

Start with [COURSE_STRUCTURE.md](COURSE_STRUCTURE.md), then the [complete lesson index](COMPLETE_LESSON_INDEX.md) or its [filterable CSV](LESSON_INDEX.csv). The [workbook catalog](WORKBOOK_CATALOG.md) finds practice files by skill. [DOWNLOAD_REPORT.md](DOWNLOAD_REPORT.md) and the [transcript availability report](TRANSCRIPT_AVAILABILITY_REPORT.md) record acquisition and permission limits. The [resource manifest](RESOURCE_MANIFEST.csv) distinguishes verified official downloads from items whose content was not individually inspected. [STUDY_PROGRESS.md](STUDY_PROGRESS.md) is for manual updates and does not alter Coursera progress.

Each of Modules 1–6 has an original guide under `05_Study_Notes`. These are not Coursera resources. Keep practice edits separate from the provider-supplied originals.

Course: [Excel Skills for Business: Essentials](https://www.coursera.org/organizations/kiron/learn/excel-essentials?specialization=excel), Macquarie University.
