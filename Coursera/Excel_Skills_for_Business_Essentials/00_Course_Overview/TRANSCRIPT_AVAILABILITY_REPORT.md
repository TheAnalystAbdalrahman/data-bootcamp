## Repeatable, normal-interface procedure

1. Open a video from the authenticated course outline.
2. Select **Files** beside **Transcript** and **Notes**.
3. If present, select the official **txt Transcript** or **WebVTT Subtitles** link for the desired language.
4. Verify that a file actually downloads. Store it with its module and record the source lesson URL.

This procedure can be repeated manually on other lessons, but their Files panels were not inspected, so availability elsewhere remains unverified. Do not infer that every video has the same formats or languages. No transcript scraping, reconstruction, or graded activity was performed.
