# Module 5 study guide: Printing Excel Spreadsheets

**Original supplementary guide.** It provides general Excel practice and no copied lesson or assessment content. Work on copies of official files.

## Important concepts

- Print Preview is the final check for paper or PDF output. Verify page count, clipping, legibility, and repeated context before printing.
- Page orientation, paper size, margins, print area, and scaling interact. Scaling a very wide sheet onto one page can make text unreadable; sometimes two pages or a different layout is better.
- Manual page breaks control where pages split. Recheck them after editing rows, columns, margins, or scaling.
- Print titles repeat selected header rows or columns on each page. They are different from a worksheet's ordinary title cell.
- Headers and footers can carry the report name, date, and page number without occupying data rows.
- Saving to PDF gives a shareable snapshot. Keep an editable `.xlsx` working copy because a PDF is not a substitute for formulas and data.

## Original mini-exercise

Make a fictional twelve-row monthly inventory report with `Item`, `Opening`, `Received`, `Used`, and `Closing`. Put `=B2+C2-D2` in `E2` and copy down. Set landscape orientation if the columns need it, inspect Print Preview, add a page number footer, and repeat the header row if the report spans pages. Export a PDF from your **practice copy** and verify the page count and readability. Do not use scaling simply to hide a layout problem.
