# Module 1 — Data Analysis with Spreadsheets

## Module outcome

Students move from opening a spreadsheet to using data to answer a practical question.

By the end of the module, students should be able to:

- recognize rows, columns, records, fields, and data types;
- inspect and clean a small dataset;
- use basic and conditional formulas;
- summarize data with PivotTables;
- choose a useful chart;
- build a simple dashboard; and
- write an evidence-based insight and recommendation.

## Teaching rhythm

Use the same cycle throughout the module:

**Explain → Demonstrate → Students copy → Students modify → Students solve**

Keep explanations under 20 minutes whenever possible. The class should spend most of its time working in the spreadsheet.

## Core analytical habit

**Question → Inspect → Calculate → Check → Interpret**

Students should distinguish among:

- **Evidence:** what the data directly shows.
- **Hypothesis:** a possible explanation that needs more data.
- **Unsupported conclusion:** a claim the available data cannot establish.
